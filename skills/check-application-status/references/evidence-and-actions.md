# Status evidence and allowed actions

## Evidence order

Use the strongest current source available:

1. authenticated portal state or direct individualized organizer/recruiter message
2. official confirmation email containing the opportunity or reference number
3. explicit user report of a completed submission or outcome
4. tracker note or pre-submit snapshot
5. third-party or generic marketing message

When strong sources conflict, preserve both, keep the safer prior status, and ask the user or flag manual verification.

## Mapping

- Receipt or successful-submission confirmation → `Submitted`
- Explicitly under review / being evaluated → `Pending`
- Interview, assessment, finalist, presentation, or next-round invitation → `Interview / Evaluation`
- Direct admission, award, selection, acceptance, or job offer → `Approved / Offer`
- Direct decline or non-selection → `Rejected`
- User or official confirmation of withdrawal → `Withdrawn`
- Opportunity cancelled, role filled without an application outcome, or deadline closed before submission → `Closed`

Do not map these to an outcome:

- invitation to apply
- newsletter or promotional congratulations
- event registration receipt when selection is separate
- application-viewed notification
- request for optional profile completion
- silence after an expected date

## Action categories

Report but do not execute without a separate request:

- missing-material upload
- interview or call scheduling
- reply to recruiter/organizer
- payment or enrollment deposit
- acceptance or decline
- travel booking or attendance confirmation
- withdrawal

Update the tracker with the message date, sender/domain, requested action, deadline with timezone, and evidence link when available. Avoid copying sensitive email contents into notes; summarize only what is needed to act.
