# CV tailoring standard

## Requirement-to-evidence map

Before editing, make a compact working table:

`Opportunity requirement | Importance | Verified evidence | CV section/bullet | Action`

Use `Required`, `Preferred`, or `Context` for importance. Valid actions are `Emphasize`, `Rewrite faithfully`, `Reorder`, `Already clear`, and `Unsupported`. Do not put the internal map into the submitted CV.

## Source priority

1. User-confirmed Ground Truth Database value
2. Current master CV statement
3. Approved reusable answer or verified submitted archive
4. User clarification for this application

Past tailored CV wording is reusable only after checking it against the current source of truth. A polished old bullet is not evidence by itself.

## Tailoring checklist

- Match the professional summary or opening profile to the opportunity's actual focus.
- Put the most relevant verified experience, projects, education, research, and skills where reviewers will see them quickly.
- Lead bullets with specific work and supported outcomes; retain exact metrics and scope.
- Prefer the opportunity's terminology when it truthfully describes the same work.
- Keep dates, titles, degree status, publication status, and locations consistent with the source of truth.
- Preserve relevant links and test that they resolve.
- Respect the requested page limit, template, language, anonymity, and file type.
- Remove comments, tracked changes, hidden text, document metadata that exposes another application, and accidental filename references before export.

## Final comparison

Return a short change log grouped as:

- `Reordered or emphasized`
- `Rewritten without factual change`
- `Removed or compressed`
- `Unsupported requirements left unclaimed`
- `Needs user confirmation`

Do not describe cosmetic punctuation or spacing changes unless they affect meaning or layout.
