# Contributing

Contributions are welcome when they keep the system person-agnostic, private by default, and safe around submissions and binding commitments.

1. Fork the repository and create a focused branch.
2. Do not add real applicant data or private service links, even as fixtures or screenshots.
3. Keep each skill focused and place lane-specific schemas in references.
4. Run `python3 scripts/validate_repo.py`.
5. Explain behavioral changes and their privacy or authorization impact in the pull request.

Please report security or privacy issues through GitHub's private vulnerability-reporting feature instead of a public issue.
