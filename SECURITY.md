# Security and privacy

Application materials contain sensitive personal data. This repository must contain only reusable instructions, schemas, and validators.

Do not commit CVs, personal facts, private Drive links or IDs, email exports, submitted answers, access tokens, cookies, passwords, one-time codes, payment data, government identity numbers, or browser profiles.

If you discover a vulnerability that could expose user data or bypass the final-review boundary, use GitHub private vulnerability reporting for this repository. Do not include real user data in the report.
