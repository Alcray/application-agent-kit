# Repository guidance

This repository contains public, person-agnostic application-agent skills.

- Never commit a real CV, applicant name, contact detail, private Drive URL/ID, tracker export, submitted answer, credential, or browser/session artifact.
- Keep runtime personal data in the user's private Google Drive workspace described by `application-agent-setup`.
- Preserve the mandatory final-review boundary in `apply-person`.
- Preserve evidence-based status transitions in `check-application-status`.
- Validate every skill and the plugin manifest before committing changes.
